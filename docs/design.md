# Fellowship 설계 문서

## 목적
2027년 대만 방문(7일 이하) 중에 현지인과 대화할 때 혼자 쓰는 iOS 앱이다.
- 상대가 중국어로 말하면, 그 말을 한국어 음성으로 바꿔 유선 이어폰에 들려준다.
- 내가 한국어로 말하면, 번체 중국어로 번역해 화면에 크게 띄운다. 그리고 상대에게 화면을 보여 준다.
- AirPods 실시간 번역 기능을 쓰지 않고 유선 이어폰으로 쓰는 것이 이 앱을 만드는 이유다.

## 목표
- 인터넷 없이(비행기 모드에서) 모든 기능이 동작한다.
- 아이폰을 손에 든 채로 대화한다.
- 상대의 중국어를 한국어 음성으로 듣고, 원문과 번역문을 화면에서도 본다.
- 내 한국어는 번체 중국어 큰 글씨로 화면에 보여 준다.

## 비목표 (만들지 않는다)
- 녹음, 대화 기록 저장
- 중국어 음성 출력 (화면 표시만 한다)
- 중국어·한국어 외의 다른 언어
- App Store 배포, 다른 사용자 지원
- 클라우드 API
- 블루투스 이어폰 지원
- 화면을 잠근 상태나 백그라운드에서의 동작
- 설정 화면

## 안티목표 (동작해도 실패로 본다)
- 현지에서 네트워크나 앱 서명 문제로 앱이 실행되지 않는 경우
- 이어폰이 빠졌을 때 번역 음성이 스피커로 크게 나오는 경우
- 말이 끝나고 번역이 나오기까지 3초보다 오래 걸리는 경우

## 제약
- 기기: iPhone Air, iOS 26
- 이어폰: USB-C 유선 이어폰(마이크 포함)
- 엔진: SpeechAnalyzer/SpeechTranscriber, Translation 프레임워크, AVSpeechSynthesizer. 모든 처리를 기기 안에서 한다.
- 설치: 무료 Apple ID로 Xcode에서 직접 설치한다.
- 외부 패키지는 쓰지 않는다. 애플 기본 프레임워크만 쓴다.

## 기술 결정
- **마이크**: 유선 이어폰 마이크를 쓴다. 이어폰이 없으면 내장 마이크를 쓴다.
- **모드**: 기본은 듣기 모드(zh-TW 인식, 번체 중국어→한국어 번역, 한국어 음성 출력)다. 화면 버튼을 누르고 있는 동안만 말하기 모드(ko-KR 인식, 한국어→번체 중국어 번역, 화면 표시)가 된다. 0.5초보다 짧게 누르면 무시한다. 자동 언어 감지는 넣지 않는다.
- **음성 출력**: 한국어 번역만 이어폰으로 읽어 준다. 읽어 줄 문장이 쌓이면 음성 속도를 높인다.
- **이어폰 분리**: 오디오 경로 변경 알림을 받아, 유선 이어폰이 빠지면 음성 출력을 즉시 멈춘다. 다시 꽂으면 자동으로 재개한다.
- **화면 꺼짐 방지**: 앱이 켜져 있는 동안 `isIdleTimerDisabled = true`
- **오디오 세션**: `.playAndRecord`

## UX 명세

### 전체 흐름
앱 실행 → 준비 확인 화면(처음 한 번, 또는 데이터가 빠졌을 때만) → 대화 화면 ⇄ 보여주기 카드

### 화면 1: 준비 확인
- 항목: 마이크 권한, 음성 인식 권한, 중국어(대만) 인식 모델, 중국어↔한국어 번역 데이터, 한국어 음성
- 각 항목은 준비됨(✓) 또는 다운로드 버튼(↓)으로 표시한다.
- 모든 항목이 준비되어야 "시작하기" 버튼이 눌린다. 다음 실행부터는 이 화면을 건너뛴다.

### 화면 2: 대화 화면 (항상 듣는 중)
- 상단: 이어폰 연결 상태("🎧 이어폰 연결됨"), 음성 끄기 토글
- 가운데: 메신저 같은 말풍선 목록
  - 상대 말풍선(왼쪽): 중국어 원문 작게, 한국어 번역 크게
  - 내 말풍선(오른쪽): 한국어 원문 작게, 중국어 번역 크게
  - 인식 중인 문장은 회색으로 실시간 표시한다.
  - 상대 말풍선을 탭하면 한국어를 다시 읽어 준다.
  - 내 말풍선을 탭하면 보여주기 카드를 다시 연다.
- 하단: 큰 "🎤 누르고 말하기" 버튼
  - 누르는 동안: 빨간색으로 바뀌고 진동이 온다. "● 듣는 중…"과 함께 내 한국어가 실시간으로 보인다.
  - 손을 떼면: 번역이 끝나는 대로 진동이 한 번 오고, 보여주기 카드가 뜬다.

### 화면 3: 보여주기 카드 (화면 전체)
- 번역된 중국어를 아주 큰 글씨로 보여 주고, 그 아래에 내 한국어 원문을 작게 보여 준다.
- 오른쪽 위에 180도 돌리기 버튼(↻)이 있다.
- 탭해야 닫힌다. 자동으로 닫히지 않는다.
- 카드를 띄운 동안에도 듣기는 계속한다.

### 상황별 동작
| 상황 | 화면 | 동작 |
|---|---|---|
| 이어폰이 빠짐 | 상단 노란 배너 "이어폰이 빠져서 음성을 껐어요" | 음성은 멈추고 말풍선은 계속 생긴다. 다시 꽂으면 음성을 자동으로 재개한다 |
| 버튼을 0.5초보다 짧게 누름 | 변화 없음 | 무시한다 |
| 내 말이 인식되지 않음 | 버튼 위에 "다시 말해 주세요" | 카드를 띄우지 않는다 |
| 번역할 문장이 밀림 | 변화 없음 | 한국어 음성 속도를 높인다 |
| 언어 데이터가 없음 | 준비 확인 화면으로 이동 | 다시 내려받게 한다 |

## 진행 단계
0. 프로젝트 준비 (SwiftUI, iOS 26+, 앱 이름 `Fellowship`)
1. UI/UX만 구현 — `ConversationViewModel` + 목업 데이터, DEBUG 전용 디버그 메뉴, 화면별 Preview. 사용자 승인 전까지 2단계 금지.
2. 백엔드 — 실기기 비행기 모드 가능성 검증(zh-TW/ko-KR 인식, 번체↔한국어 번역, 한국어 고품질 음성) 후 실제 엔진 연결. 문장 큐·속도 조절, 0.5초 미만 입력 무시, 이어폰 분리 시 정지에 단위 테스트.
3. 최종 검증 — 목표/비목표/안티목표 기준 리뷰, 실기기 테스트 목록, README 출국 전 점검 목록.
